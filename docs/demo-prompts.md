# Demo prompts

Paste any of these into Muse Code with Ori connected.

**Yoga studio (the main demo)**
> I run a small yoga studio with outdoor classes in the park. I want an app where students sign in with Google, see my weekly timetable, join a waitlist when a class is full, and get an email when a spot opens. Warn everyone the day before if rain is forecast. Get Ori to build it.

**Neighborhood bakery**
> I own a bakery. I want customers to pre-order bread for pickup the next morning and get a reminder email at 7am. Ask Ori to build this for me.

**Dog walker**
> I walk dogs for about 20 clients. I need an app where owners book walks, see which walker is coming, and get a photo when the walk is done. Have Ori build it.
